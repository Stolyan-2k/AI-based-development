# Анализ прироста и темпов роста временного ряда

## Описание
Скрипт предназначен для анализа динамики показателя во времени.
Он рассчитывает:
-Абсолютный прирост (diff())
-Темп роста ((t / t-1) * 100)
-Темп прироста (темп роста - 100)

а также строит визуализацию изменения показателя и его динамических характеристик.

## Функционал
Функция analyze_growth(df, date_col, value_col) выполняет следующие шаги:

1. Сортирует данные по дате.
2. Рассчитывает:
  - Абсолютный прирост (Абс_прирост)
  - Темп роста (Темп_роста_%)
  - Темп прироста (Темп_прироста_%)
3. Строит график, на котором отображаются:
  - Исходный показатель
  - Абсолютный прирост
  - Темп роста (%)
  - Темп прироста (%)
4. Выводит:
  - Средний темп роста
  - Факт положительного/отрицательного прироста
5. Возвращает обновлённый DataFrame и средний темп роста.
