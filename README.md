# Обработка насыщенности изображений

## Описание
Этот проект позволяет изменять насыщенность изображений с помощью библиотеки **OpenCV**.  
Программа проходит по указанной директории, обрабатывает все изображения и выводит результат в сравнении: слева — оригинал, справа — версия с изменённой насыщенностью.

## Возможности
- Обработка всех изображений в выбранной папке
- Поддержка форматов: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.tiff`
- Регулировка коэффициента насыщенности (`saturation_scale`)
- Разделение логики:
  - `process_image` — обработка изображения
  - `show_images` — вывод результата
  - `process_directory` — обработка всех файлов в директории
